Keysharp is installed

Open Keysharp from Applications to get started, or Keyview to edit a script. If you installed only for yourself, the apps are in the Applications folder of your home folder.

If you added terminal commands, open a new Terminal window to use keysharp and keyview.

macOS asks for Accessibility, Input Monitoring or Screen Recording permission when a script first needs it.

To uninstall, click Uninstall Keysharp in the Keysharp dashboard, open Uninstall Keysharp on the disk image, or run keysharp-uninstall.
